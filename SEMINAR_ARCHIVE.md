# Runtime; Python Seminar Archive

The Study Room includes the **actual, user-provided Runtime; Python seminar decks** for weeks 1–4, optimized for faster web preview.

| Week | Main content | Pages | Website file |
|---|---|---:|---|
| 1 | Python installation, execution modes, variables, comments, numeric and string types | 34 | `public/seminars/week-1.pdf` |
| 2 | Scalar types, operators, sequence and string basics | 41 | `public/seminars/week-2.pdf` |
| 3 | Lists, tuples, indexing, slicing, dictionaries, conditions and loops | 39 | `public/seminars/week-3.pdf` |
| 4 | Review, function definition, arguments, local/global scope, modules and packages | 44 | `public/seminars/week-4.pdf` |

## Presentation and operation

- **스터디룸 → 세미나 복습**: weekly **document list**. Choose a week and preview the original slide layouts inside the page, open the PDF in another tab, or download it.
- **스터디룸 → 미니 퀴즈**: five graded multiple-choice questions for each uploaded week, with answer explanations and restart.
- **스터디룸 → 자료실**: official Python, R and GitHub learning references. The former arbitrary practice CSV link is removed.
- **동아리 소개**: compact introduction of three operating roles, clearly marked as role examples until actual officeholders are supplied.
- All subpages: staggered fade/slide-in headline animation, with reduced-motion support.

## No paid service required

All four seminars are hosted in the GitHub Pages `public/seminars/` directory and quizzes are client-side React. No account, hosted database, or paid backend is needed.

**Publication note:** The four files supplied for this presentation have been optimized into visually equivalent PDFs. These optimized slide images are raster-based and may no longer contain selectable text. Keep the originals separately for editing, archiving or high-resolution distribution. This repository contains only files intentionally committed for web preview.

The quiz contents in `src/data/seminarWeeks.js` reference topics and code patterns from those four original decks. Exercises are newly authored to support practice; they are not claimed to be verbatim copies of the slides.
